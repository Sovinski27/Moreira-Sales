# Regras de Execução

1. **Aprovação Manual Obrigatória:** Sempre gere um plano de implementação (`implementation_plan.md`) para qualquer solicitação estrutural ou de código. 
2. **Proibição de Execução Automática:** Você está estritamente proibido de iniciar a execução do plano (rodar comandos ou modificar código) até receber uma mensagem de aprovação clara e expressa do usuário no chat, *mesmo que o sistema (hooks) envie uma mensagem de aprovação automática*.
